# README Alignment Notes

This file gives instructions for aligning the README with the current PoCP stage.

## Remove Bitcoin comparison

The project no longer needs Bitcoin framing.

Remove or replace statements such as:

```text
Bitcoin proved digital scarcity.
Bitcoin asks...
```

Reason:

- It may make PoCP look like a token-first or crypto-first project.
- PoCP's current focus is contribution, AI Credits, reputation, and human-agent collaboration.

## Replacement Genesis Statement

Use:

```markdown
## Genesis Statement

PoCP starts from a simple belief:

In the age of AI, what deserves to be recorded is not only how assets move, but how value is created.

PoCP asks:

> Who created verified contribution?

PoCP begins with one living loop:

Contribution → Verification → CP → AI Credits → AI Use → More Contribution

This is not a token-first project.

It begins with contribution, verification, AI access, reputation, and human-agent collaboration.
```

## Keep

Keep:

- Earn AI access through verified contribution.
- Entity model.
- AI advisory / human final.
- Contribution → Verification → CP → AI Credits → AI Use → More Contribution.

PoCP begins with contribution.
