# FAQ

## Is PoCP a token or crypto project?

**No.** PoCP AI Commons is not a token-first crypto project.

Sprint Alpha does not issue a tradable token. **AI Credits** are internal usage rights for AI features (e.g. AI Chat) — earned through verified contribution and registration grants, not purchased as speculative assets.

PoCP begins with **contribution**, not financialization.

## What are AI Credits?

AI Credits meter access to AI-powered features in the platform. Each AI Chat message burns a small number of credits (default: 5). Credits are not money and are not designed for trading.

See [AI-CREDITS-GUIDE.md](./AI-CREDITS-GUIDE.md).

## Does AI approve contributions?

**No.** AI verifiers provide **advisory** review only (scores, feedback, suggested rewards). **Finalization** is policy-automated: witness quorum + traceable delegate (any Entity type — Human, Agent, LLM, …).

See [ENTITY-EQUALITY.md](./ENTITY-EQUALITY.md) · [HUMAN-REVIEW-GUIDE.md](./HUMAN-REVIEW-GUIDE.md) (optional human-as-finalizer deployments).

## What is the first loop?

```text
Login → Wallet (starter AI Credits) → AI Chat
→ Submit contribution → Multi-witness verify → Policy auto-finalize
→ CP + AI Credits → Ledger + Graph Merkle → Portable proof
```

## What is not in v0.1?

- Token issuance or trading
- DAO governance
- Unlimited free AI
- AI-only final decisions
- On-chain requirement for basic use

## Can someone fork PoCP and run a private instance?

**Yes** — the project uses the [MIT License](../LICENSE). Anyone may download, modify, and deploy privately or publicly.

That does **not** let them own the protocol, other nodes’ ledgers, or federation trust. See [OPENNESS-AND-ANTI-MONOPOLY.md](./OPENNESS-AND-ANTI-MONOPOLY.md).
