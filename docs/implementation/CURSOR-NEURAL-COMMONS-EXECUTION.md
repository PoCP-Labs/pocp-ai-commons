# Cursor Neural Commons Execution Guide

## Goal

Implement PoCP Neural Commons Network through small PRs.

## Rule

Do not implement everything at once.

## PR Sequence

1. README + architecture docs.
2. Entity and Capability schemas.
3. Token Measurement internal accounting.
4. Invocation Ledger.
5. Settlement Layer.
6. Rule-Based Neural Routing.
7. Compute Node basic adapter.
8. Reputation and Neural Graph.

## Public Core Rule

Public repo may include schemas, basic interfaces, mock implementations, and reference services.

Do not include commercial routing optimizer, advanced anti-abuse weights, managed compute scheduler, private risk models, or enterprise secrets.
