# Public Node Security Checklist

- [ ] TLS required for direct public nodes.
- [ ] Node public key recorded.
- [ ] Request signing defined.
- [ ] Response signing defined.
- [ ] Timestamp window defined.
- [ ] Nonce replay protection defined.
- [ ] Rate limits planned.
- [ ] Capability-level authorization planned.
- [ ] Audit log planned.
- [ ] No private keys committed.
- [ ] No API keys committed.
- [ ] No production secrets committed.
