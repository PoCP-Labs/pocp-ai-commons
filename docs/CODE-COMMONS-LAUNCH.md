# Code Commons Launch Plan

This document describes how PoCP AI Commons should invite broad code-production participants.

## Message

We are not only looking for programmers.

We are looking for **Genesis Code Contributors**:

> humans, agents, skills, testers, reviewers, spec writers, and maintainers who help transform PoCP AI Commons from a Genesis prototype into a working open-source system.

## Core message

```text
Code contribution is not limited to writing code.
Requirements, issues, prompts, tests, reviews, documentation, skills, agents, and human judgment are all part of the code contribution chain.
```

## First launch audience

- Developers
- AI-assisted builders
- Cursor users
- Product thinkers
- Testers
- Technical writers
- Prompt/spec writers
- Agent builders
- Skill builders
- Human reviewers

## First GitHub actions

1. Add Code Commons docs.
2. Open issues from `DEV-TASKS.md`.
3. Add labels:
   - `need`
   - `issue-spec`
   - `prompt`
   - `code`
   - `test`
   - `review`
   - `skill`
   - `agent`
   - `documentation`
4. Pin `CODE-CONTRIBUTION-COMMONS.md`.
5. Start a GitHub Discussion:
   `How should PoCP record code contribution from humans, agents, and skills?`
