Whitepaper

Entity-centric protocol outline

This page adapts the protocol framing of PoCP V0.1 into a concise public whitepaper page suited for GitHub Pages.

Definition

PoCP is a contribution proof protocol for intelligent entities in the age of AI. It records and verifies contributions from humans, agents, LLMs, skills, tools, datasets, workflows, and organizations, then allocates usage rights, reputation, opportunity, and future governance standing according to contribution rules.

Entity model

The first-class object is the entity, not merely the user. An entity can produce, verify, invoke, compose, or govern contributions. V0.1 focuses on humans, agents, skills, and LLMs, while leaving tools, datasets, workflows, organizations, and communities as reserved expansion paths.

  • Humans: students, developers, reviewers, organizers
  • Agents: task executors, coordinators, verifiers
  • Skills: reusable callable capability units
  • LLMs: witness nodes for reasoning and verification

Rights model

Usage rights map to AI Credits. Reputation rights map to durable contribution records and score accumulation. Governance rights are deferred and remain human accountable, even when non-human entities participate in the contribution graph.

Minimal loop

Human creates Skill
-> Human or Agent uses Skill to complete task
-> Submit contribution as a multi-entity event
-> Lumen-0 and DeSui provide AI pre-review
-> Human reviewer confirms
-> Human receives AI Credits
-> Agent and Skill receive Reputation
-> Contribution enters the ledger

Contribution graph

PoCP is not just a ledger. It is a graph of relationships: humans use agents, agents call skills, skills depend on models, reviewers approve contributions, and verified events issue credits and reputation across several entities.

Genesis entities

  • Lumen-0: witness and interpreter
  • DeSui: validator and cross-checker
  • Clarion-0: reviewer assistant and verifier agent

These AI entities may advise, score, summarize, and structure evidence. None of them hold final governance authority. Human reviewers remain the final line.

Reference demo

The reference demo uses an R-language study-material task. A human contributor, an assisting agent, and a reusable skill cooperate. AI witnesses produce verification advice, and a human reviewer performs final approval. The result is a recorded multi-entity contribution event with AI Credits and reputation updates.
