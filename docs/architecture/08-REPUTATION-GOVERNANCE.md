# Reputation & Governance

## Purpose

Reputation measures contextual trust.

Governance controls protocol parameters and evolution.

## Reputation Types

- Human Reputation
- Agent Reputation
- Skill Reputation
- LLM Reliability
- Tool Reliability
- Dataset Trust
- Workflow Success Rate
- Compute Node Reliability
- Verifier Accuracy
- Reviewer Accuracy
- Organization Trust

## Governance Power

Governance should not be token-only.

Suggested formula:

```text
Governance Power =
Token Stake
× Reputation Coefficient
× Recent Contribution Coefficient
× Role Eligibility
× Risk Adjustment
```
