# Neural Routing

## Purpose

Neural Routing maps tasks to capabilities.

## Routing Inputs

- task type
- required output
- budget
- privacy requirement
- urgency
- risk tolerance
- preferred entities
- excluded entities

## Routing Outputs

- execution plan
- selected entities
- selected capabilities
- estimated cost
- estimated risk
- routing explanation

## MVP

Start with rule-based routing.

Do not include commercial routing optimizer in the public repo.
