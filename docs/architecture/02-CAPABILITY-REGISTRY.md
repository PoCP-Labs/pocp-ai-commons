# Capability Registry

## Purpose

The Capability Registry records what an Entity can do.

## Capability Examples

- coding
- review
- translation
- reasoning
- teaching
- data processing
- workflow execution
- GPU inference
- GPU training
- storage
- verification
- governance

## Core Fields

```text
capability_id
entity_id
capability_type
name
unit
price_model
accepted_units
verification_method
availability
reputation_score
risk_level
metadata
```

## Principle

Capability is the bridge between Entity and Task.
