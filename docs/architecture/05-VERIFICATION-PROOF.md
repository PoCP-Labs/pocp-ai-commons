# Verification & Proof

## Purpose

Verification determines whether a contribution claim, invocation output, or compute usage is valid.

## Verification Types

- AI advisory verification
- multi-model verification
- human review
- peer review
- compute output validation
- benchmark
- log proof
- challenge-response
- TEE / ZK reserved

## Principle

AI can advise.

Human or accountable governance remains final for high-impact decisions.
