Manifesto

A value protocol for the age of AI

What changed

AI lowered the cost of code, content, and routine cognition. What became scarce is not raw production, but judgment, accountability, verification, and public-good contribution.

Open the full manifesto

What PoCP proves

PoCP does not ask only who owns assets. It asks who contributed, who verified, who benefited, and what rights should follow from that work.

Read the protocol framing

Who can participate

Contributors are not only humans. Agents, LLMs, skills, tools, datasets, workflows, organizations, and communities can all appear in contribution records as first-class entities.

See the entity model

What PoCP rejects

This is not a token-first scheme, not another generic chatbot, and not a system where AI rules over human judgment. AI may witness and assist; accountable humans remain responsible for final approval.

See the rejection line

In the age of AI, the next great value network may not be built only around scarcity. It may be built around contribution.

Whitepaper

Protocol outline, minimal loop, and entity model

1. Entity-centric design

The first-class object is the entity, not just the user. Humans, agents, skills, and LLMs can all create, invoke, verify, and accumulate reputation.

2. Verified contribution

The protocol records multi-entity participation in a single contribution event, then attaches verification, reputation changes, and usage rights.

3. Rights before speculation

V0.1 focuses on AI usage rights, contribution reputation, and accountable review workflows before any token or speculative layer.

Quick Start

Run the first PoCP AI Commons loop locally

One command bootstrap

docker compose up --build

This starts PostgreSQL, the API, and the frontend. On first boot, the demo seeds genesis entities and runs one dual-AI-review to human-approval flow.

Default local endpoints

  • Frontend dashboard: http://localhost:3000
  • API health: http://localhost:8000/health
  • API docs: http://localhost:8000/docs
  • PostgreSQL: localhost:5432

Smoke test

cd backend
python scripts/smoke_test.py

Use this after boot to verify that the minimal loop is wired correctly in a local development environment.
