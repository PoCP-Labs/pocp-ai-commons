# Community Launch Plan

This document describes how to invite global contributors to co-build PoCP AI Commons.

## Positioning

PoCP AI Commons is an open-source contribution proof network for the age of AI.

Core message:

> Earn AI access through verified contribution.

Community message:

> Help build an open AI commons where humans, agents, and skills can contribute, be verified, build reputation, and earn AI access.

## Launch Goal

Recruit the first 30–100 Genesis Contributors across:

- Developers
- AI verifier builders
- Skill builders
- Human reviewers
- Task designers
- Researchers
- Community builders
- Translators
- Pilot users

## First 20 Issues

Create issues based on:

- GOOD_FIRST_ISSUES.md
- README improvements
- Verifier tests
- AI Chat UI
- Skill definitions
- Contribution Graph UI
- Anti-abuse tests
- Governance FAQ

## Contributor Rewards in Genesis Stage

Non-financial rewards:

- Genesis Contributor record
- Contribution Badge
- Reputation record
- AI Credits once MVP supports it
- Future governance eligibility

Important:

Do not promise token rewards, financial returns, or investment gains.
