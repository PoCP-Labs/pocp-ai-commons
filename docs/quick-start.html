Quick Start

Run the first contribution loop locally

This page distills the current developer quick start into a public-facing setup guide for PoCP AI Commons.

Boot the stack

docker compose up --build

This boots PostgreSQL, the backend API, and the frontend dashboard. Alembic migrations run on startup.

Default endpoints

  • Frontend dashboard: http://localhost:3000
  • API health: http://localhost:8000/health
  • API docs: http://localhost:8000/docs
  • PostgreSQL: localhost:5432 with pocp / pocp

What the demo seeds

First boot seeds genesis entities such as Lumen-0 and DeSui, prepares the R-language study scenario, and completes one dual-AI-verify to human-approve loop.

Database mode

PostgreSQL is the default path for Docker and long-term development. SQLite remains an optional local-only mode for lightweight experimentation.

Smoke test

cd backend
python scripts/smoke_test.py

Run the smoke test after boot to verify the seeded loop and the main service path are functional.
