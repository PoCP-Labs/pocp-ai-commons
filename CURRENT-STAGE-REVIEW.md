## What has been established

### 1. Core thesis

PoCP is a contribution proof protocol for the age of AI.

It asks:

> Who created verified contribution?

### 2. First application

PoCP AI Commons:

> Earn AI access through verified contribution.

### 3. First loop

```text
Contribution → Verification → CP → AI Credits → AI Use → More Contribution
```

### 4. Entity model

PoCP uses Entity as the core participant model.

An Entity may be Human, Agent, LLM, Skill, Tool, Dataset, Workflow, Organization, or Community.

The first MVP focuses on:

```text
Human + Agent + Skill
```

### 5. AI role

AI is advisory.

Human review remains final.
