# Bitcoin-Inspired PoCP Network

## Core Idea

PoCP can learn from Bitcoin's network architecture without copying Bitcoin mining or becoming a token-first project.

Bitcoin proves value transfer without a central bank.

PoCP should prove AI capability invocation, contribution, verification, settlement, and reputation without a central AI platform.

## Mapping

| Bitcoin | PoCP |
|---|---|
| Bitcoin Node | PoCP Entity Node |
| Wallet Address | Entity DID / Node Public Key |
| Transaction | Invocation / Proof / Settlement Event |
| Mempool | Pending Invocation / Proof / Settlement Pool |
| Block | EventBatch |
| Blockchain | ProtocolEvent Ledger |
| Miner | Verifier / Indexer / Settlement Node |
| Proof of Work | Proof of Contribution / Capability / Verification |
| UTXO / Balance | TokenAccount |
| SPV Light Node | PoCP Light Node |
| Block Explorer | Reputation Graph Explorer |
