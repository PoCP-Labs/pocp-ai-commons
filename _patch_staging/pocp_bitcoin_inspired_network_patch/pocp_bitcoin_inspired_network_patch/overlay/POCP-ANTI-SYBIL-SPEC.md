# PoCP Anti-Sybil Spec

## Threats

```text
fake nodes
fake capabilities
mutual invocation farming
fake proofs
fake compute usage
collusive reviewers
duplicate contribution claims
identity farming
```

## Controls

```text
DID / public key identity
optional proof of personhood
stake / bond
reputation decay
duplicate proof detection
graph anomaly detection
rate limits
reviewer calibration
challenge mechanism
slashing
risk-based verification
```
