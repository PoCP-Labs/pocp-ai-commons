# Capability Schema

Capability defines what an Entity can do.

```json
{
  "capability_id": "cap_code_review_001",
  "entity_id": "skill_001",
  "node_id": "node_001",
  "capability_type": "code_review",
  "name": "Python Code Review",
  "unit": "skill_invocation",
  "price": {"AIC": 5},
  "input_schema": {},
  "output_schema": {},
  "verification_method": "human_review",
  "risk_level": "low",
  "availability": "available",
  "version": "v0.1"
}
```
