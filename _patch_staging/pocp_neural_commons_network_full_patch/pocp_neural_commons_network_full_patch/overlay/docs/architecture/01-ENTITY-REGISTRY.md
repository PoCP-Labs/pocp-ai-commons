# Entity Registry

## Purpose

The Entity Registry records every participant in the PoCP Neural Commons Network.

## Entity Types

- Human
- Agent
- LLM
- Skill
- Tool
- Dataset
- Workflow
- Compute Node
- Verifier Node
- Reviewer Node
- Organization
- Community
- Sponsor
- Protocol Treasury
