# Commercial Boundary

## 1. Purpose

This document defines which parts of PoCP may be commercial, restricted, or provided under separate terms.

PoCP follows an Open Core model.

The open-source layer builds trust and ecosystem adoption.

The commercial layer supports sustainability, security, enterprise use, and advanced operations.

## 2. Commercial Modules

The following may be commercial or restricted:

### 2.1 Advanced Anti-Abuse Intelligence

Includes:

- graph-based fraud detection;
- CP farming detection;
- AI Credits abuse detection;
- Compute Credits abuse detection;
- Sybil detection;
- collusive review detection;
- replay attack detection;
- risk model weights;
- private blacklists;
- anomaly scoring.

### 2.2 Commercial Neural Routing

Includes:

- AI-based task routing optimization;
- commercial cost optimization;
- enterprise SLA routing;
- premium capability ranking;
- high-value skill discovery;
- agent reliability optimization;
- private routing policies.

### 2.3 Managed Compute Scheduling

Includes:

- GPU scheduler;
- compute provider selection;
- price optimization;
- node reliability model;
- commercial compute routing;
- SLA enforcement;
- supplier integrations.

### 2.4 Enterprise Governance Console

Includes:

- enterprise organization admin;
- private reviewer workflows;
- internal sponsor pools;
- compliance reporting;
- audit dashboards;
- enterprise permissions;
- private governance rules.

### 2.5 Commercial API Gateway

Includes:

- API key management;
- rate limits;
- billing;
- usage analytics;
- organization quotas;
- enterprise support;
- partner integrations.

### 2.6 Advanced Reputation and Risk Models

Includes:

- reviewer accuracy model;
- agent reliability model;
- skill ranking model;
- compute reliability model;
- organization trust model;
- graph propagation scoring;
- commercial scoring calibration.

## 3. What Should Remain Open

The commercial boundary must not hide protocol-level trust rules.

The following should remain open:

- schemas;
- basic reference implementation;
- basic contribution ledger;
- basic CP / AI Credits accounting;
- basic human review flow;
- basic reputation updates;
- basic routing examples;
- basic settlement examples;
- SDKs;
- API examples;
- documentation.

## 4. Enterprise Offering

Future enterprise offerings may include:

- hosted PoCP node;
- private AI Commons deployment;
- enterprise contribution ledger;
- enterprise review workflow;
- managed AI Credits;
- managed Compute Credits;
- custom Skill / Agent marketplace;
- commercial neural routing;
- compliance dashboard;
- dedicated support.

## 5. Principle

Do not commercialize trust itself.

Commercialize advanced operations, intelligence, support, and enterprise readiness.

PoCP begins with contribution.
