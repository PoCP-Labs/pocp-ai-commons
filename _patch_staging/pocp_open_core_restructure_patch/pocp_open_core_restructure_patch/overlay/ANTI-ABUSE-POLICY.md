# Anti-Abuse Policy

## 1. Purpose

PoCP rewards verified contribution.

Any reward system can be attacked.

This policy defines the public anti-abuse principles while keeping sensitive detection details restricted.

## 2. Abuse Types

PoCP should defend against:

- fake contributions;
- repeated evidence;
- self-approval;
- collusive reviews;
- AI-generated spam;
- CP farming;
- AI Credits farming;
- Compute Credits farming;
- fake compute usage;
- replay attacks;
- Sybil attacks;
- reviewer manipulation;
- reputation farming;
- sponsor pool abuse;
- settlement manipulation.

## 3. Public Basic Rules

The following basic rules may be open source:

- evidence required;
- self-approval blocked;
- duplicate evidence warning;
- contribution rate limits;
- review rate limits;
- credit spend limits;
- required reviewer role;
- ledger record integrity checks;
- replay protection;
- audit trail.

## 4. Restricted Advanced Rules

The following should not be fully public:

- graph anomaly thresholds;
- fraud scoring weights;
- private risk signatures;
- behavioral detection patterns;
- blacklists;
- collusion detection parameters;
- high-risk route rules;
- commercial abuse intelligence.

## 5. Human Final Review

AI may assist abuse detection.

Human or accountable governance should handle severe penalties, appeals, and slashing decisions.

## 6. Appeals

Users and entities should be able to appeal:

- rejected contributions;
- withheld rewards;
- reputation penalties;
- slashing;
- suspension.

## 7. Principle

Anti-abuse must protect the contribution economy.

It must not become opaque arbitrary control.

PoCP begins with contribution.
