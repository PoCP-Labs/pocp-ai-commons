A contributor may be added when they make a meaningful early contribution, such as:

- Accepted PR
- Significant documentation contribution
- Verifier implementation
- Skill contribution
- Governance or anti-abuse research
- Community launch support
- Pilot design
- Human review work

## Contribution Memory Principle

PoCP should use itself to remember its builders.

Every meaningful contribution should eventually become:

```text
Contribution Event
→ Verification
→ Reputation
→ Rights
→ Ledger Memory
```

PoCP begins with contribution.
