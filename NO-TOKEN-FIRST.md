# No Token First

PoCP is not a token-first project.

At the current stage, PoCP focuses on:

- verified contribution;
- CP;
- AI Credits;
- reputation;
- contribution ledger;
- human-agent collaboration;
- contribution graph.

## Why no token now?

A protocol token should not be the starting point.

PoCP first needs to prove:

```text
Real contribution
→ real verification
→ real AI Credits
→ real AI use
→ more contribution
```

Without this loop, a token would be a narrative without a network.

## Current rights

PoCP currently focuses on three non-financial rights:

### 1. CP — Contribution Points

CP records contribution value.

CP is not designed as a tradable asset in the MVP.

### 2. AI Credits

AI Credits are usage rights.

They allow contributors to access AI capabilities.

AI Credits are not securities, not investment products, and not a promise of financial return.

### 3. Reputation

Reputation records long-term contribution reliability.

## Future token condition

A protocol token, if ever introduced, must come after:

1. real contribution networks;
2. real AI Credits usage;
3. anti-abuse mechanisms;
4. reliable contribution ledger;
5. contextual reputation system;
6. governance need;
7. value pool;
8. legal and compliance analysis.

## Official position

```text
PoCP is not a token-first project.

PoCP begins with contribution, verification, AI access, reputation, and human-agent collaboration.

Any future protocol token must be the result of a mature contribution network, not the starting point.
```

PoCP begins with contribution.
