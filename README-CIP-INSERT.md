## PoCP Capability Internet Protocol

PoCP AI Commons is the first application scenario of the larger **PoCP Capability Internet Protocol**.

PoCP Capability Internet Protocol is the decentralized contribution, invocation, settlement, and reputation protocol for AI capability and compute networks.

AI Commons proves the first loop:

```text
Contribution
→ Verification
→ CP / AI Credits
→ AI Use
→ More Contribution
```

The larger protocol expands this into:

```text
Entity
→ Node
→ Capability
→ Invocation
→ Proof
→ Verification
→ Settlement
→ Reputation Graph
```

Core protocol objects:

```text
Entity
NodeProfile
Capability
Invocation
Proof
Verification
Settlement
TokenAccount
ReputationRecord
ProtocolEvent
```
