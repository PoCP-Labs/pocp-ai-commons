# PoCP Incentive Spec

## Purpose

Bitcoin incentivizes miners. PoCP should incentivize useful network work.

## Rewarded Work

```text
Capability provision
Compute provision
Proof verification
Human review
Indexing
Relay service
Storage
Security auditing
Protocol maintenance
Governance participation
```

## No PoW Mining

PoCP should not reward meaningless hash races.

PoCP should reward useful, verified work.
