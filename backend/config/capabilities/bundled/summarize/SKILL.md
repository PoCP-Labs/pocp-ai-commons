# Summarize

Use this skill when a contribution task needs structured summaries of study materials, articles, or meeting notes.

## Workflow

1. Confirm the source text or URL is provided in task evidence.
2. Produce a summary with: key points, definitions, and open questions.
3. Return output suitable for human review and PoCP contribution submission.

## PoCP attribution

Record this skill as `skill_provider` on the contribution and attach the summary as evidence.
