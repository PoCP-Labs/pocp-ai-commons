# Genesis Code Contributors

This file records early contributors to the code production chain of PoCP AI Commons.

A Genesis Code Contributor does not have to be only a programmer.

A contributor may help with:

- requirements;
- issues;
- specs;
- prompts;
- code;
- tests;
- reviews;
- documentation;
- skills;
- agents;
- architecture;
- deployment;
- security;
- product feedback.

## Contributor Roles

| Role | Meaning |
|---|---|
| Requirement Contributor | Defines real user or platform needs |
| Issue Writer | Converts needs into actionable GitHub issues |
| Spec Contributor | Writes API specs, data models, prompts, or acceptance criteria |
| Human Developer | Writes or integrates code |
| Agent Contributor | Generates code, tests, docs, or review suggestions |
| Skill Builder | Creates reusable capabilities for development |
| Test Contributor | Verifies behavior and catches bugs |
| Documentation Contributor | Makes the project understandable |
| Reviewer | Reviews code, specs, tests, and AI-generated outputs |
| Maintainer | Makes merge and release decisions |

## How to be added

You may be added when you make a meaningful early contribution, such as:

- accepted PR;
- high-quality issue;
- useful specification;
- tested bug report;
- implementation patch;
- AI verifier adapter;
- contribution graph improvement;
- documentation improvement;
- human review rubric;
- reusable Skill;
- verified Agent-assisted code contribution.

## Future ledger migration

When PoCP AI Commons supports real contribution recording, early code contributions may be migrated into the PoCP ledger as verified Contribution Events.
