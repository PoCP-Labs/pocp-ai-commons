# Neural Commons Master Plan

## Goal

Build PoCP into a protocol network for distributed intelligence and compute.

## Strategic Position

PoCP is not only an AI usage platform.

PoCP is:

```text
Entity Registry
+ Capability Registry
+ Neural Routing
+ Invocation Ledger
+ Verification Layer
+ Token Measurement
+ Settlement Layer
+ Reputation Network
+ Governance Layer
+ Neural Graph
```

## Design Principles

### 1. Entity-Centric

Everything begins with Entity.

Humans, agents, skills, LLMs, tools, datasets, workflows, compute nodes, organizations, and reviewers are all Entities.

### 2. Capability-Based

Entities are useful because they expose capabilities.

Capability is the bridge between Entity and Task.

### 3. Invocation-Recorded

Every meaningful call should be recordable.

Who called what, at what cost, with what output, and with what result?

### 4. Contribution-Verifiable

Outputs become contribution claims only after evidence, verification, and review.

### 5. Token-Measured

PoCP uses CP, AIC, CC, and PT internal units to measure contribution, AI usage, compute usage, and settlement.

### 6. Reputation-Weighted

Token cannot buy reputation.

Reputation must be contextual and based on performance.

### 7. Human-Accountable

AI can assist verification and governance.

Humans and accountable governance remain responsible for final decisions.

### 8. Open Core

The protocol skeleton must be open.

Commercial intelligence can be reserved.

## Target Modules

### Entity Registry

Stores all actors.

### Capability Registry

Stores all callable capabilities.

### Neural Routing

Maps tasks to capabilities.

### Invocation Ledger

Records calls and usage.

### Verification & Proof

Reviews evidence and outputs.

### Token Measurement

Accounts for CP, AIC, CC, PT.

### Settlement Layer

Distributes value across contributors.

### Reputation Governance

Updates trust and governance eligibility.

### Neural Graph

Visualizes and queries network relations.

## Success Definition

A task can be routed to multiple entities, executed, verified, settled, and reflected in reputation and graph.

PoCP begins with contribution.
